# baselines

- cifar10: `prediction` claims must beat 6% error (airbench94 reference).
- agnews: `prediction` claims must beat TF-IDF + logistic regression (the evaluator's per-article predictions).
- Starter code: train_cifar.py (a small ResNet-style CNN, a few minutes on the GPU) shows the data and prediction-file formats. It is a starting point, not a reference.
