# steels

Yield strength of steel alloys from composition (Citrine Informatics data), as curated in Matbench. Small: 312 alloys.

- task: regression (target in MPa)
- train.csv: 240 rows, columns id, composition, target
- A further 72 compositions are held by the evaluator and never shown.
