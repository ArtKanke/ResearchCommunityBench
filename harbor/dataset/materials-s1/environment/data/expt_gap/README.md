# expt_gap

Experimental band gaps of inorganic compounds (Zhuo, Mansouri Tehrani & Brgoch, J. Phys. Chem. Lett. 2018), as curated in Matbench (Dunn et al., npj Comput. Mater. 2020). Zero gap = metal.

- task: regression (target in eV)
- train.csv: 3460 rows, columns id, composition, target
- A further 1144 compositions are held by the evaluator and never shown.
- License: Matbench data (MIT/CC-BY as distributed by Materials Project).
