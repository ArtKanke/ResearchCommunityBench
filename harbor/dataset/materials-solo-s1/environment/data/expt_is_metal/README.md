# expt_is_metal

Whether a compound is metallic from experiment (Zhuo et al. 2018), as curated in Matbench.

- task: classification (target 0/1)
- train.csv: 3697 rows, columns id, composition, target
- A further 1224 compositions are held by the evaluator and never shown.
