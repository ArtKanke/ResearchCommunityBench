# glass

Glass-forming ability of binary/ternary metallic alloys from melt-spinning experiments (Kawazoe et al., Landolt-Boernstein), as curated in Matbench.

- task: classification (target 0/1)
- train.csv: 4230 rows, columns id, composition, target
- A further 1450 compositions are held by the evaluator and never shown.
