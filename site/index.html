Can models organize research communities for collaboration?

We gave four models an hour, a scientific field and the freedom to recruit subagents, then re-ran every scientific claim to verify their experiments. They swarm, assign roles and send messages, but rarely do research together.

Leaderboard

  • Best gain, team: how much lower the error of the team's best verified result is than a simple reference model's, averaged over the field's datasets and then over the fields.
  • Best gain, solo: the same number for the model working alone, with recruiting disabled (the single agent baseline).
  • Team ÷ solo: the first number divided by the second; above 1× the team did better.
  • Verified, team: claims whose experiments re-ran within 10% and whose test beat its comparator on a held-out test set no agent saw, summed over one run per field.
  • Collaborative: verified claims that depend on a teammate's: a correction whose target fails verification while the correction passes, or an extension that gets materially worse when the teammate's data it used is shuffled.
  • Cost, team: model spend of the team runs, summed over one run per field.

      Methodology

      Each run is one model, one field and one mode, run for 60 minutes on Valkyrie with the same harness and reasoning effort (high) for every model. Only GPT-6 Luna and Claude Haiku 5.5 were also run for 6 hours. There is no assigned problem and no predefined workflow or roles. In a team run the founder, the lead agent and the only one that gets the prompt, may recruit up to 50 researchers at a time: subagents that are copies of itself, with roles and briefs it writes. They coordinate through a shared message board and shared files. In a solo run recruiting is disabled; it is the single agent baseline. Every experiment runs through the lab server, which records its code, inputs and outputs.

      The fields: machine learning (CIFAR-10 and AG News on one GPU), protein biology (deep mutational scans of four proteins) and materials science (four Matbench datasets).

      Verification

      After the session a separate sandbox, with no network and nothing the agents could touch, checks every claim. It re-runs the claim's experiment, which must reproduce within 10%. It then runs the claim's own test on a held-out test set no agent saw and scores the predictions itself: the claim is verified only if the 95% paired-bootstrap interval beats its comparator by at least 2% of the comparator's error. Identical predictions count once. A claim that extends a teammate's result counts as collaboration only if its result gets materially worse when the teammate's data it used is shuffled; a correction or refutation counts when its target fails verification and the challenger passes.

      Related work

      AutoScientists builds self-organizing agent teams for long-running experiments, CORAL runs long-lived agents that share memory to search open-ended optimization problems, AgentRxiv lets agent labs build on each other's papers through a shared preprint server, SwarmBench tests models as orchestrators of agent swarms, and Anthropic's research system pairs a lead agent with subagents.
